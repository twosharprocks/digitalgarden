My read on likely consolidation targets#

  • Keep broad navigation tags only if you actively browse by them. #personal is extremely broad and appears on many unrelated notes, so it may be better as a folder/property/default rather than a tag.
  • Treat status/lifecycle markers as a property rather than tags where possible: status: seed/tree/reference/... is cleaner than mixing #seed, #tree, #reference, #unread, etc.
  • Meal tags are useful if you search by ingredient/cooking style, but the one-off tags are likely over-granular. Consider a smaller controlled set such as meal, meal-prep, quick, breakfast, snack, high-protein, plus maybe major cuisines/proteins only when repeated.
  • Source/article workflow tags like source, unread, article, books, ai-content seem useful if they drive reading/review workflows.
  • One-off topical tags like #toastie, #croissant, #dumplings, #fakenews, etc. are better as words in the note title/body unless you expect to collect more notes under them.
