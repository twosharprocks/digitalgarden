Threat Modelling

#cyber-security  #threat-modelling 

Methologies

PASTA - Process for Attack Simulation and Threat Analysis Focuses on aligning considerations of business objectives with technical requirements.

STRIDE - Spoofing, Tampering, Repudiation, Information Disclosure, DoS, Elevation Focuses on identifying what can fail in the system being modelled.

OWASP - Open Web Application Security Project Focuses on identifying possible threats, prioritizing risks, and planning mitigation strategies. It is mainly used with web and desktop applications.

  • Determine assessment scope
  • Identify threat agents.
  • Identify potential attacks.
  • Identify exploitable vulnerabilities.
  • Prioritize identified risks.

SQL Injection (SQLi) [A03:2021-Injection]

SQL vulnerabilities allow attackers to insert malicious SQL commands to exfiltrate, modify, or delete data. Some hackers use SQL to gain root access to the target system. The most common vulnerability is using unsanitized user inputs. Strip out any element in user-supplied inputs that the server could execute as SQL code by using Prepared Statements.
