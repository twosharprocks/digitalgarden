Basics

Using Fabric: input | fabric options -sp pattern_name |save "File Name" Options

  • -s (Stream output),
  • -p / –pattern (Pattern to choose)
  • -c / –context (context file use)
  • -l / –list (List available patterns)
  • –listmodels, –model, –changedefaultmodel
  • –remoteollamaserver (IP of local AI server to use)

Modify API keys and save folder: nano ~/.config/fabric/.env Update: fabric -u / –update (Reverts default to gpt-4o)`
