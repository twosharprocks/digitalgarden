CMD

Commands for Cmd Shell & PowerShell - COMPREHENSIVE Helpful Command Line Commands

Core

  • cd or chdir Change directory (Linux = cd)
  • dir List directory contents (Linux = ls)
  • md or mkdir Create directory (Linux = mkdir)
  • copy Copy file (Linux = cp)
  • move Move (Cut/Paste) files (Linux = mv)
  • clip Copies to Clipboard
  • del or erase Delete files/directories (Linux = rm or shred)
  • rd or rmdir Remove directory if empty (Linux = rm)
  • find Search a file for a specific string (Linux = grep)
  • exit Close CMD (Linux = exit)
  • type Show contents of file (Linux = cat)
  • cls Clear screen
  • findstr Find string
  • clip - Add to clipboard

Environment Variables

  • set Shows all PC Environment Variables
  • %CD% Current Directory
  • %DATE% Current Date
  • %OS% Windows
  • %ProgramFiles% C:\Program Files
  • %ProgramFiles(x86)% C:\Program Files (x86)
  • %TIME% Current Time
  • %USERPROFILE% C:\Users{username}
  • %SYSTEMDRIVE% C:\
  • %SYSTEMROOT% C:\Windows

Network

  • ipconfig IP Config (Options: /all /release /renew /displaydns /flushdns)
  • getmac MAC Info (Options: /v)
  • netsh
    • netsh wlan show wlanreport
    • netsh interface show interface
    • netsh interface ip show address
    • netsh advfirewall set allprofiles state off Turn off Windows defender
  • ping ping website.address
    • Options: -t (continuous pinging)
  • fping ping multiple ip addresses at once
    • Options: -g (ping all IPs in the following range)
  • tracert “trace route”
    • Options: -d (no domain names)
  • netstat (Options: -o to list PIDs, -e -t 5 to show sent/recieved stats every 5 seconds)
  • route print [computer routing table] (add to add specific route, delete)
  • netsh wlan show profile wifiname key=clear Show saved wifi password
  • nslookup
    • nslookup -type=ptr networkname.com

System Management

  • systeminfo Provides system information
  • driverquery List all drivers (even drivers not in device manager)
  • powercfg (Option required: /energy /batteryreport)
  • assoc File associations
    • eg. assoc .mp4=vlc (Set .mp4 association to VLC)
  • chkdsk Check disk
    • Options /f (error search & fix) /r (check physical sectors)
  • sfc System file check
    • Options /scannow
  • DISM Deployment Image Servicing and Management
    • Options: /Online /Cleanup-Image /CheckHealth OR /ScanHealth OR /RestoreHealth
  • cipher Wipe empty disk space and encrypts files
  • tasklist List tasks
    • tasklist | findstring script To find “script”
  • taskkill Kill task
    • taskkill /f /pid## /f to force /pid to identify process by id#
  • shutdown
    • shutdown /r /fw /f /t 0 (reboot into BIOS)
  • wmic Windows Management Instrumentation Command-Line (Process management)
    • wmic is being replaced with Powershell
    • wmic Starts interactive mode (shell-like), commas used for multiple properties
    • Input format: wmic [global switches] [alias] [verbs] [properties]
      • eg. wmic /APPEND:report.txt logicaldisk get caption, filesystem, freespace
    • Global Switches
      • /APPEND
    • Alias
      • os, Logicaldisk,
    • verbs
      • get
    • properties
      • caption, /value, buildnumber, filesystem, freespace, size, volumeserialnumber
  • net Manage user accounts, groups, and password policies

Cheese Pull Apart Bread

#meal  #snack  #bread  #cheese  #oven  #indulgent 

Ingredients

  • Bread loaf (sourdough or cob) - 1
  • Mozzarella - 200g (cubed or shredded)
  • Butter - 3 tbsp (melted)
  • Garlic - 2 cloves (minced)
  • Parsley (optional)
  • Seasoning
    • Salt
    • Pepper

Directions

  1. Cut the bread in a crosshatch pattern (do not slice all the way through)
  2. Stuff mozzarella into the cuts throughout the loaf
  3. Mix melted butter with garlic and seasoning
  4. Pour or brush mixture over the bread, ensuring it gets into the gaps
  5. Wrap loosely in foil and bake at 180°C for 15 minutes
  6. Uncover and bake another 5–10 minutes until crispy and melted
  7. Serve immediately and pull apart

Macros

  • Calories - 420
  • Protein - 14g
  • Carbs - 38g
  • Fat - 24g

Notes

  • Identified based on “cheese pull” style construction
  • Designed for visual melt/stretch rather than high-protein efficiency
  • Best served immediately while cheese is hot and elastic

Cheeseburger Bowls

#meal  #beef  #bowl  #burger  #high-protein  #meal-prep  #to-try 

Ingredients

  • Ground beef - 500g
  • Potatoes (or fries) - 400g
  • Cheese - 1 cup (shredded)
  • Pickles - to taste
  • Lettuce - 1–2 cups (shredded)
  • Onion - 1/2 (diced)

Burger Sauce

  • Mayonnaise - 3 tbsp
  • Ketchup - 1 tbsp
  • Mustard - 1 tsp
  • Pickle juice - 1 tsp

Directions

  1. Cook potatoes or fries until crispy
  2. Cook ground beef with salt and pepper until browned
  3. Mix burger sauce ingredients in a bowl
  4. Assemble bowls with potatoes, beef, cheese, lettuce, onion, and pickles
  5. Drizzle with burger sauce and serve

Macros

  • Calories - 520
  • Protein - 40g
  • Carbs - 35g
  • Fat - 22g

Notes

  • Identified as cheeseburger-style bowl based on user verification
  • Typical “burger in a bowl” structure (beef + potato base + sauce)

Chicken & Chorizo One Pan Rice

#meal  #chicken  #chorizo  #rice  #one-pan  #high-protein  #meal-prep  #easy 

Ingredients

  • Chicken breast - 600g (diced)
  • Chorizo - 120–150g (sliced)
  • Rice - 250–300g (uncooked, rinsed)
  • Onion - 1 (diced)
  • Red and yellow peppers - 2 (chopped)
  • Garlic - 3 cloves (minced)
  • Chicken stock - 500–700ml
  • Tomato paste - 2 tbsp
  • Oil - 1 tbsp

Seasoning

  • Smoked paprika - 2 tsp
  • Garlic powder - 1 tsp
  • Salt
  • Pepper
  • Chilli (optional)

Directions

  1. Heat oil in a large pan and cook chorizo until it releases oils
  2. Add onion, peppers, and garlic, cooking until softened
  3. Add chicken and cook until browned
  4. Stir in tomato paste and seasoning
  5. Add rice and mix to coat in flavours
  6. Pour in chicken stock and bring to a simmer
  7. Cover and cook for 15–20 minutes until rice is tender and liquid absorbed
  8. Fluff and serve

Macros

  • Calories - 600
  • Protein - 45g
  • Carbs - 60g
  • Fat - 18g

Notes

  • Confirmed from indexed reel + multiple matching recipes :contentReference[oaicite:4]{index=4}
  • Similar to simplified paella-style cooking (one-pan absorption method)
  • Very strong meal prep option
