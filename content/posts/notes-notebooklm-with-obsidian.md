Notebook LM accepts Markdown
Notebook LM does not use personal data to train the model

Research and Execution
- Sources - Import your notes, youtube videos, audio files
- Save Notes so you can keep output
- Convert to Source if you want to use output as a source later
- Copy & Paste conversation back into Obsidian (tag with `containsAI`)
- Output an audio overview - listen while on a walk

Personal Plan
- Bring in a bundle of sources that interest you, then ask questions

Social Media Generator
- Bringing in various sources, then have AI conversation to tease out what you actually want from it
- Leveraging the Feynmann Technique - You learn better when you teach others. [Video - Master Learning by Teaching](https://youtu.be/YiM2ZUGxowQ?si=duZ17PKkrPAPWUNN)
	- Add Video into sources, then use existing details to guide AI on what you want
	- Export to PDF if you're losing formatting
Dataview - [Automatic Obsidian Note Indexing](https://youtu.be/-5IcgqlwYMA)
Community Plugin - Better Export PDF
- Export all your daily notes into one PDF so NotebookLM can handle it
Community Plugin - [Smart Connections](https://www.youtube.com/watch?v=ce2PVHyuRtA) (Direct AI Integration into Obsidian)
