# MD Formatting
[Extended Syntax](https://www.markdownguide.org/extended-syntax/)
[Text colours](https://github.com/orgs/community/discussions/31570) = `<code style="color : red">text</code>` 
Front Matter: `---` at start of new file (Switch to Source Mode with `Ctrl+Shift+S`)

*single asterisks = italics*
**double asterisks = bold**
***Triple asterisks = italics and bold***

`<ins>` & `</ins>` <ins>will underline</ins>
~~Strikethrough uses 2 tilde characters at each end~~
==Two equal signs highlight text==
`Single angle quote makes the text a script`
> The "Greater than" character turns it into a quote

- Dash and space at the start of of a line makes a bulletpoint
 - [ ] Use a dash to create a bullet, then square brackets around a space to create an empty checkbox
 - [x] Replace the space (between the square brackets) with an x to strike the checkbox & text

For emoji, put `:` on either side of [shortcode](https://gist.github.com/rxaviers/7360908) 
- ⛺ `:tent:` 
- 🌱 `:seedling:` 🌲 `:evergreen_tree:` 🌼 `:blossom:` 
- 🌌 `:milky_way:` 🌍 `:earth_africa:` 
- ✅`:white_check_mark:`  ❌ `:x:`
